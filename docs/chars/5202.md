# Guia de Build: Akaashi SP - ID 5202

Este documento detalha a build otimizada para o **Keiji Akaashi SP**, o Levantador (S) essencial para liberar o verdadeiro potencial do Bokuto e controlar o ritmo do jogo.

---

## 1. Conjunto de Potenciais (Sets)
O Akaashi foca em levantamentos consistentes para maximizar o ataque do seu time.

*   **Opção Ideal: 4 Peças [Levantamento Preciso / Precise Set]**
    *   *Lógica:* Como ele não possui mecânicas defensivas tão vitais quanto o Kenma, o foco do Akaashi é prover Levantamento puro para o seu principal atacante.
*   **2 Peças:** 2 Peças secundárias focadas em Levantamento (Set) ou Finta de Levantador para maximizar atributos brutos de Set.

## 2. Atributos Principais (Main Stats)

*   **Slot II: Levantamento (Set) ou Percepção (Awareness)**
    *   *Lógica:* Percepção ajuda ele a conseguir Levantamentos Críticos, enquanto Levantamento aumenta o bônus de dano de quem recebe a bola. Ambos são válidos.
*   **Slot IV: Reflexo (Reflex) ou Bloqueio (Block)**
    *   *Lógica:* Depende de como você utiliza ele. Como ele joga na frente (Rede) para levantar pro Bokuto e costuma ajudar no bloqueio triplo, status de Bloqueio pode ter valor nele. Reflexo é mais universal.
*   **Slot VI: Levantamento (Set) ou Técnica de Ataque (Attack Technique)**
    *   *Lógica:* Status clássico de Setter para buffar as jogadas de forma passiva.

## 3. Sub-Atributos Ideais (Sub-stats)
Busque otimizar o papel de maestro:
1.  Levantamento (Set)
2.  Percepção (Awareness)
3.  Técnica de Ataque (Attack Technique)
4.  Reflexo (Reflex)

## 4. Cartões de Memória (Memory)
*   **Memória do Akaashi SP (Própria)**
    *   *Lógica:* Vital para a sinergia direta e moral do time (especialmente com Bokuto).
*   **Memória Universal de Levantador (Koganegawa)**
    *   *Lógica:* Boa alternativa se não possuir a memória SP, pois continua auxiliando nos atributos de Set.
