# Guia de Build: Koganegawa SP - ID 5402

Este documento detalha a build otimizada para o **Kanji Koganegawa SP**, um Levantador (S) incrivelmente alto que também foca em defesas robustas na rede.

---

## 1. Conjunto de Potenciais (Sets)
Diferente da maioria dos levantadores, Koganegawa tem atributos e habilidades que o tornam uma muralha.

*   **Opção Ideal: 4 Peças [Levantamento Preciso / Precise Set]**
    *   *Lógica:* Essencial para a função base dele, que é levantar bolas de qualidade.
*   **2 Peças:** 2 peças de Bloqueio Preciso para maximizar sua vantagem na rede.

## 2. Atributos Principais (Main Stats)

*   **Slot II: Levantamento (Set) ou Percepção (Awareness)**
*   **Slot IV: Reflexo (Reflex) ou Bloqueio (Block)**
    *   *Lógica:* Koganegawa ajuda muito no bloqueio da equipe. Bloqueio extra garante defesas eficientes.
*   **Slot VI: Levantamento (Set) ou Técnica de Ataque**

## 3. Sub-Atributos Ideais (Sub-stats)
1.  Levantamento (Set)
2.  Bloqueio (Block)
3.  Percepção (Awareness)
4.  Técnica de Ataque (Attack Technique)
