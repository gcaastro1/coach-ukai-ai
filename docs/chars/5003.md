# Guia de Build: Kenma (Sakura) SP - ID 5003

Este documento detalha a build otimizada para o **Kenma Kozume (Sakura) SP**, um Levantador que atua como Receiver primário e foca em escalar agressivamente o atributo de **Reflexo** para dar buffs massivos ao time.

---

## 1. Conjunto de Potenciais (Sets)
A regra fundamental para o Kenma SP é focar em **Reflexo** acima de qualquer efeito de conjunto de 4 peças. Reflexo não apenas ajuda a defender, mas a passiva dele converte Reflexo em Percepção (crítico) no levantamento, e (se Ressonância 2) transfere o Reflexo como Dano Crítico para o Atacante!

*   **Obrigatório: 2 Peças [Defesa Potente]**
    *   *Lógica:* Garante +7.5% de Reflexo direto. NUNCA faça uma build do Kenma SP sem essas 2 peças.
*   **Opção A (Foco em Sub-stats / Híbrido): 2 Peças [Levantamento Preciso] + 2 Peças [Defesa Potente] + 2 Peças Variadas**
    *   *Lógica:* O melhor uso do Kenma muitas vezes não passa por fechar 4 peças. Você deve equipar as peças (nos slots flexíveis) que possuírem os **maiores valores de Reflexo como Sub-status**, ignorando o efeito de 4 peças.
*   **Opção B (Se você usar Fintas): 4 Peças [Finta do Levantador / Setter Dump] + 2 Peças [Defesa Potente]**
    *   *Lógica:* Recomendado apenas se você gosta de jogar fazendo o levantador atacar direto (Setter Dump).

## 2. Atributos Principais (Main Stats)

*   **Slot II: Levantamento (Set) ou Percepção (Awareness)**
    *   *Lógica:* Depende do nível da Skill 3 (Passiva). Se for Nível 1, use Percepção para ajudar no crítico. Se for Nível 2+ (ou se jogar junto com o Hinata SP, que dá muito buff de Percepção para o Kenma por causa dos Bonds), use Levantamento puro.
*   **Slot IV: Reflexo (Reflex)**
    *   *Lógica:* O atributo mais crítico do personagem. OBRIGATÓRIO.
*   **Slot VI: Levantamento (Set) ou Técnica de Ataque**
    *   *Lógica:* Ambas servem, mas Levantamento costuma ter maior valor para ele. Mais uma vez, escolha a peça que tiver o melhor *sub-stat de Reflexo*.

## 3. Sub-Atributos Ideais (Sub-stats)
Apenas um sub-stat realmente importa:
1.  **Reflexo (Reflex)** - Tente chegar o mais perto possível dos 40% só pelos status para, junto com buffs in-game, beirar os 100%.
2.  Levantamento (Set) / Percepção (Awareness)

## 4. Cartões de Memória (Memory)
*   **Memória do Kenma SP (Própria)**
    *   *Lógica:* A mais potente para extrair seu kit.
*   **Memória do Akaashi ou Koganegawa**
    *   *Lógica:* Alternativas universais de levantador que oferecem bom suporte tático caso não possua a dele.
