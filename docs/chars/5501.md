# Guia de Build: Oikawa SP - ID 5501

Este documento detalha a build otimizada para o **Toru Oikawa SP**, o "Grande Rei", Levantador com capacidade extrema de saque e distribuição tática.

---

## 1. Conjunto de Potenciais (Sets)
Oikawa brilha tanto na distribuição de jogadas quanto marcando Aces diretos no saque.

*   **Opção A (Foco em Levantamento): 4 Peças [Levantamento Preciso / Precise Set]**
    *   *Lógica:* Maximiza o poder do time.
*   **Opção B (Foco em Saque / Pinch Server): 4 Peças [Saque Feroz / Fierce Serve] ou [Saque Preciso]**
    *   *Lógica:* Maximiza a chance de quebrar a recepção inimiga.
*   **2 Peças:** 2 Peças do outro set (se usou Levantamento, use Saque aqui, e vice-versa).

## 2. Atributos Principais (Main Stats)

*   **Slot II: Levantamento (Set) ou Saque (Serve)**
*   **Slot IV: Percepção (Awareness) ou Reflexo (Reflex)**
    *   *Lógica:* Percepção ajuda muito ele a conseguir críticos tanto no saque quanto nos levantamentos.
*   **Slot VI: Técnica de Ataque (Attack Technique) ou Saque (Serve)**
    *   *Lógica:* Técnica de Ataque aumenta o multiplicador geral, beneficiando ambos.

## 3. Sub-Atributos Ideais (Sub-stats)
1.  Saque (Serve)
2.  Levantamento (Set)
3.  Percepção (Awareness)
4.  Técnica de Ataque (Attack Technique)

## 4. Cartões de Memória (Memory)
*   **Memória do Oikawa SP (Própria)**
    *   *Lógica:* Traz todos os stats necessários para o "Grande Rei" governar a quadra.
