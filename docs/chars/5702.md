# Guia de Build: Hirugami SP - ID 5702

Este documento detalha a build otimizada para o **Hirugami**, baseada no meta de bloqueio, interações de rotação e mecânicas de *cooldown* (tempo de recarga).

---

## 1. Conjunto de Potenciais (Sets)
A regra de ouro para o Hirugami SP é **nunca usar o set "Forceful God" (Deus Implacável)**, pois o bônus de Reflexo é desperdiçado (o kit dele já garante bloqueio crítico quando o adversário faz um corte crítico).

*   **Opção A (Mais Condicional): 4 Peças [Block Movement / Movimento de Bloqueio]**
    *   *Lógica:* Só utilize este set de 4 peças se você puder garantir que, em **todas** as rotações, haverá outro jogador do tipo Bloqueio (Block) na rede junto com o Hirugami. 
*   **Opção B (Mais Segura/Geral): 4 Peças [Precise Block / Bloqueio Preciso]**
    *   *Lógica:* Se você não puder garantir múltiplos bloqueadores na linha de frente em todas as rotações, use este set.
*   **2 Peças:** O set de bloqueio que sobrar (aquele que você não usou para fechar as 4 peças), ignorando sempre o Forceful God.

## 2. Atributos Principais (Main Stats)
A escolha de status principais do Hirugami SP foca em não desperdiçar multiplicadores, dada a natureza do seu kit.

*   **Slot II: Flexível**
    *   *Lógica:* O atributo principal não importa muito para a função defensiva primária dele. Escolha a peça que tiver os **melhores sub-atributos (sub-stats)**.
*   **Slot IV: Empenho (Spirit)**
    *   *Lógica:* Como o Hirugami já garante o acerto crítico no bloqueio contra cortes críticos, investir em Reflexo ou puramente no atributo de Bloqueio gera menos retorno. O Empenho atua como o Dano Crítico do bloqueio, e ele não conseguirá obter Empenho suficiente naturalmente para diluir esse atributo, tornando-o extremamente eficiente.
*   **Slot VI: Bloqueio % (Block %)**
    *   *Lógica:* Não utilize Técnica de Defesa (Defense Technique). O próprio kit do Hirugami já providencia buffs imensos de técnica ofensiva e defensiva para a equipe. Colocar mais técnica aqui causará diluição severa. Vá direto no status puro de Bloqueio %.

## 3. Sub-Atributos Ideais (Sub-stats)
Busque otimizar o bloqueio bruto e o modificador de crítico defensivo:
1.  Bloqueio % (Block %)
2.  Empenho (Spirit)

## 4. Cartões de Memória (Memory)
*   **A Melhor Opção Defensiva: Memória do Aone SP**
    *   *Lógica:* Em termos de poder defensivo bruto para bloquear, a memória do Aone SP fornece os melhores atributos de mitigação e defesa pura.
*   **Opção Ofensiva / Club Contest: Memória do Hirugami SP (Própria)**
    *   *Lógica:* Esta memória oferece menos defesa, mas fornece um buff de Ataque Rápido (Quick Attack) para a equipe, auxiliando na pontuação.
    *   *Atenção:* O efeito passivo dessa memória exige que existam **pelo menos 4 personagens com o rótulo de Bloqueio (Block)** na quadra. Se você cumprir esse requisito, o buff permanece ativo até mesmo se o Hirugami for substituído pelo Líbero no fundo da quadra!
