# Guia de Build: Tsukishima SP - ID 5301

Este documento detalha a build otimizada para o **Kei Tsukishima SP**, um Bloqueador Central (MB) de extrema inteligência que utiliza "Read Block" (Bloqueio de Leitura) e aplica debuffs.

---

## 1. Conjunto de Potenciais (Sets)
Foco total em leitura e consistência no bloqueio.

*   **Opção Ideal: 4 Peças [Bloqueio de Movimento / Block Movement]**
    *   *Lógica:* Melhora seus atributos de bloqueio quando atuando em conjunto com o time e maximiza sua resistência no longo prazo das jogadas.
*   **2 Peças:** 2 Peças de [Bloqueio Preciso] para completar o combo.

## 2. Atributos Principais (Main Stats)

*   **Slot II: Flexível (Priorize Subs)**
*   **Slot IV: Reflexo (Reflex) ou Técnica de Defesa (Defense Technique)**
    *   *Lógica:* Reflexo ajuda a conseguir bloqueios críticos para aplicar passivas de bloqueio com força.
*   **Slot VI: Bloqueio (Block %)**
    *   *Lógica:* Mandatório para MB.

## 3. Sub-Atributos Ideais (Sub-stats)
1.  Bloqueio (Block)
2.  Reflexo (Reflex)
3.  Técnica de Defesa (Defense Technique)
4.  Empenho (Spirit)

## 4. Cartões de Memória (Memory)
*   **Memória do Tsukishima SP (Própria)**
    *   *Lógica:* Aplica debuffs e aumenta muito a retenção tática dele na rede.
