# Guia de Build: Kuroo SP - ID 5302

Este documento detalha a build otimizada para o **Tetsuro Kuroo SP**, o maestro defensivo do Nekoma, conhecido pelo bloqueio colaborativo (Commit Block / Read Block).

---

## 1. Conjunto de Potenciais (Sets)
Kuroo precisa de conjuntos que maximizem sua liderança defensiva.

*   **Opção Ideal: 4 Peças [Bloqueio de Movimento / Block Movement]**
    *   *Lógica:* Brilha quando ele atua junto com outros bloqueadores na rede, engatilhando buffs adicionais de bloqueio de equipe.
*   **2 Peças:** 2 Peças [Bloqueio Preciso / Precise Block].

## 2. Atributos Principais (Main Stats)

*   **Slot II: Flexível (Priorize Subs)**
*   **Slot IV: Empenho (Spirit) ou Reflexo (Reflex)**
    *   *Lógica:* Reflexo para acionar mais crítico defensivo, Empenho para o dano do bloqueio.
*   **Slot VI: Bloqueio (Block %)**
    *   *Lógica:* Fundamental para subir a taxa de defesa pura.

## 3. Sub-Atributos Ideais (Sub-stats)
1.  Bloqueio (Block)
2.  Reflexo (Reflex)
3.  Empenho (Spirit)
4.  Técnica de Defesa (Defense Technique)

## 4. Cartões de Memória (Memory)
*   **Memória do Kuroo SP (Própria)**
    *   *Lógica:* Otimiza perfeitamente o seu estilo de capitão defensivo.
