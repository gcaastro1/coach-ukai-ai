 # Guia de Build: Tendo SP - ID 5601

Este documento detalha a build otimizada para o **Satori Tendo SP**, o Mestre do Guess Block.

---

## 1. Conjunto de Potenciais (Sets)
O Tendo SP se baseia quase que inteiramente em sua habilidade "Guess Block" para punir os atacantes inimigos sem depender de bloqueio tático conjunto.

*   **Opção Ideal: 4 Peças [Defesa Potente]**
    *   *Lógica:* Tendo pode ser jogado de forma mais agressiva na defesa. Forceful God buffa a habilidade especial dele.
*   **2 Peças:** [Bloqueio Preciso / Precise Block] para status extra.

## 2. Atributos Principais (Main Stats)

*   **Slot II: Flexível (Priorize Subs)**
*   **Slot IV: Reflexo (Reflex)**
    *   *Lógica:* Essencial para Guess Block Crítico, onde a força monstruosa do Tendo reside.
*   **Slot VI: Bloqueio (Block %)**
    *   *Lógica:* O coração do MB.

## 3. Sub-Atributos Ideais (Sub-stats)
1.  Bloqueio (Block)
2.  Reflexo (Reflex)
3.  Empenho (Spirit)
4.  Técnica de Defesa (Defense Technique)

## 4. Cartões de Memória (Memory)
*   **Memória do Tendo SP (Própria)**
    *   *Lógica:* A mais aconselhável.
