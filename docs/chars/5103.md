# Guia de Build: Aone SP - ID 5103

Este documento detalha a build otimizada para o **Takanobu Aone SP**, um Bloqueador Central (MB) de puro poder de bloqueio bruto (Iron Wall).

---

## 1. Conjunto de Potenciais (Sets)
Aone é focado em bloqueio pesado, bloqueios de leitura (Read Block) e parando completamente os atacantes inimigos.

*   **Opção Ideal: 4 Peças [Bloqueio Preciso / Precise Block]**
    *   *Lógica:* Maximiza seu principal status (Bloqueio) e concede poder adicional aos seus "Soft Blocks" e bloqueios puros. Ele é o verdadeiro pesadelo dos atacantes.
*   **2 Peças:** 2 Peças do set de [Movimento de Bloqueio] ou qualquer set defensivo para buffar seu Bloqueio e Empenho.

## 2. Atributos Principais (Main Stats)

*   **Slot II: Flexível (Priorize Subs)**
    *   *Lógica:* Não importa muito o status principal. Busque o que tiver mais Bloqueio nos sub-stats.
*   **Slot IV: Reflexo (Reflex) ou Empenho (Spirit)**
    *   *Lógica:* Reflexo aumenta as chances de conseguir um "Bloqueio Crítico". Empenho aumenta a potência (o dano mitigado) desse bloqueio crítico. Como a habilidade dele já foca bastante na defesa pura, qualquer um dos dois é excelente.
*   **Slot VI: Bloqueio (Block %)**
    *   *Lógica:* Aumenta diretamente a principal virtude dele.

## 3. Sub-Atributos Ideais (Sub-stats)
Busque a muralha impenetrável:
1.  Bloqueio (Block)
2.  Reflexo (Reflex)
3.  Empenho (Spirit)
4.  Técnica de Defesa (Defense Technique)

## 4. Cartões de Memória (Memory)
*   **Memória do Aone SP (Própria)**
    *   *Lógica:* É indiscutivelmente a melhor carta de bloqueio do jogo para mitigar ataques. Se tiver a memória SP do Aone, ele se torna um colosso.
*   **Memória de Bloqueadores (Kuroo/Tsukishima)**
    *   *Lógica:* Cartas defensivas UR focadas em bloqueio servem de bom quebra-galho.
