# Guia de Build: Sugawara SP - ID 5102

Este documento detalha a build otimizada para o **Koshi Sugawara SP**, um personagem incrivelmente versátil que pode atuar tanto como "Pinch Server" (especialista em saque) quanto como Levantador Primário/Secundário.

---

## 1. Conjunto de Potenciais (Sets)
O Sugawara SP exige que você decida qual será a função dele no seu time antes de equipar os potenciais.

*   **Opção A (Pinch Server): 4 Peças [Saque Preciso / Precise Serve]**
    *   *Lógica:* Se o objetivo dele for entrar exclusivamente para sacar e marcar pontos de Ace, este é o melhor set.
*   **Opção B (Levantador Tradicional): 4 Peças [Levantamento Preciso / Precise Set]**
    *   *Lógica:* O básico para focar na distribuição de jogadas.
*   **Opção C (Híbrido de Status brutos): 2 Peças [Levantamento Preciso] + 2 Peças [Saque Preciso] + 2 Peças [Finta do Levantador]**
    *   *Lógica:* Se você quer maximizar o atributo bruto de Levantamento (cada par dá +15% Set).

## 2. Atributos Principais (Main Stats)

*   **Slot II: Saque (Serve), Levantamento (Set) ou Percepção (Awareness)**
    *   *Lógica:* Use Saque se for Pinch Server. Se for Levantador, Levantamento ou Percepção são ótimos, pois Percepção melhora a taxa de crítico tanto para saques quanto para levantamentos.
*   **Slot IV: Bloqueio (Block) ou Recepção (Receive)**
    *   *Lógica:* **Varia conforme a posição dele na quadra.** A passiva (Skill 1) dele buffa os Bloqueadores se ele estiver na Rede, e buffa os Recebedores se ele estiver no Fundo. Se ele for Pinch Server (joga só no fundo), use **Recepção**. Se for jogar como Levantador na frente, use **Bloqueio**.
*   **Slot VI: Técnica de Ataque (Attack Technique)**
    *   *Lógica:* A opção mais segura. A Técnica de Ataque afeta *tanto o saque quanto o levantamento*.

## 3. Sub-Atributos Ideais (Sub-stats)
Busque otimizar:
1.  Técnica de Ataque (Attack Technique)
2.  Percepção (Awareness)
3.  Saque / Levantamento (dependendo da sua função primária)
4.  Recepção / Bloqueio (dependendo da posição)

## 4. Cartões de Memória (Memory)
*   **Memória do Sugawara SP (Própria)**
    *   *Lógica:* Feita sob medida para ele.
*   **Memória de Levantador Gratuita da Loja de Desafio (Budget)**
    *   *Lógica:* O Sugawara consome muita estamina (Stamina) por conta das mecânicas dele. A carta gratuita da loja, que restaura +12 de estamina quando ela cai abaixo de 30, possui uma sinergia absurda com ele e o torna um dos poucos personagens que utilizam essa memória com perfeição.
*   **Memória do Akaashi ou Koganegawa**
    *   *Lógica:* Excelentes suportes universais para levantadores.
