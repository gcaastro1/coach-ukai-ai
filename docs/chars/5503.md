# Guia de Build: Ushijima SP - ID 5503

Este documento detalha a build otimizada para o **Wakatoshi Ushijima SP**, o Atacante Oposto (OP) supremo de Shiratorizawa, focado inteiramente em pura destruição ofensiva sem limites.

---

## 1. Conjunto de Potenciais (Sets)
Ushijima não requer delicadeza, apenas pura Força.

*   **Opção Ideal: 4 Peças [Vibração de Potência]**
    *   *Lógica:* Maximiza o ataque bruto (Power Attack) que ele utiliza para atropelar até os bloqueios triplos.
*   **2 Peças:** 2 peças adicionais de Força ou Precisão de Saque (já que o saque dele também é devastador).

## 2. Atributos Principais (Main Stats)

*   **Slot II: Força (Strength) ou Ataque Potente (Power Attack)**
    *   *Lógica:* O núcleo do seu dano.
*   **Slot IV: Percepção (Awareness)**
    *   *Lógica:* Essencial para críticos mortais.
*   **Slot VI: Técnica de Ataque (Attack Technique)**
    *   *Lógica:* Multiplicador essencial para ele escalar infinitamente.

## 3. Sub-Atributos Ideais (Sub-stats)
Foque em obliterar a quadra inimiga:
1.  Força (Strength)
2.  Percepção (Awareness)
3.  Técnica de Ataque (Attack Technique)
4.  Ataque Potente (Power Attack)
