# Guia de Build: Iwaizumi SP - ID 5502

Este documento detalha a build otimizada para o **Hajime Iwaizumi SP**, Wing Spiker (WS) focado na força bruta para passar pelo bloqueio adversário.

---

## 1. Conjunto de Potenciais (Sets)
O Iwaizumi é o clássico ás confiável do Aoba Johsai.

*   **Opção Ideal: 4 Peças [Vibração de Potência]**
    *   *Lógica:* Traz a força de corte máxima e poder crítico.
*   **2 Peças:** 2 Peças com bons Sub-atributos ou Reflexo se desejar uma rotação levemente mais defensiva no fundo de quadra.

## 2. Atributos Principais (Main Stats)

*   **Slot II: Força (Strength) ou Ataque Potente (Power Attack)**
*   **Slot IV: Percepção (Awareness)**
    *   *Lógica:* Crucial para que o ataque do ás não seja parado.
*   **Slot VI: Técnica de Ataque (Attack Technique)**

## 3. Sub-Atributos Ideais (Sub-stats)
1.  Força (Strength)
2.  Percepção (Awareness)
3.  Técnica de Ataque (Attack Technique)
4.  Ataque Potente (Power Attack)

## 4. Cartões de Memória (Memory)
*   **Memória do Iwaizumi SP (Própria)**
*   **Memória do Ushijima UR** (Universa para atacantes de força)
