## 🏆 Guia e Dicas

### 🎮 Como Jogar
KENJI FUTAKUCHI (Depois da Aula) é o atacante versátil que controla o tempo da partida.

## Mecânica Principal
* **Adaptabilidade:** Ele consegue se ajustar conforme o rali desenrola, sendo capaz de realizar defesas importantes e finalizar com ataques técnicos que desestabilizam o bloqueio adversário.
* **Sinergia:** Combina muito bem com levantadores de precisão. O segredo é usar a sua capacidade de leitura de jogo para estar sempre posicionado onde a bola vai sobrar.
* **Gestão de Energia:** Utilize a build com regeneração de Empenho para que ele permaneça ativo durante os momentos de maior pressão, mantendo a agressividade necessária para finalizar os pontos.

- **Atributos Principais (Slots II, IV, VI):**
