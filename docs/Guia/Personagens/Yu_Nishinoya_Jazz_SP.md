## 🏆 Guia e Dicas

### 🎮 Como Jogar
YU NISHINOYA (Jazz) é o pilar que sustenta o ataque do time.

## Mecânica Principal
* **Proteção:** A mecânica dele é converter defesas perfeitas em buffs de **Empenho** para os atacantes. O objetivo é receber todas as bolas de forma que o levantador sempre tenha um passe perfeito.
* **Sinergia:** Combina com times que precisam de um líbero que não apenas salva a bola, mas que inicia a transição ofensiva. Ele não deve apenas defender, mas 'limpar' o caminho para o ataque.
* **Dica de Posicionamento:** Mantenha-o sempre na zona de defesa, onde o seu kit de habilidades pode brilhar contra saques adversários e ataques de ponta.

### ⚙️ Potenciais Recomendados (Builds)
**Opção 1: Guardião do Time (Líbero)**
- **Conjunto:** 4x Recepção Auxiliada + 2x Defesa Potente
- **Lógica:** O set 'Recepção Auxiliada' de 4 peças é indispensável para maximizar a sua função principal. O set de 2 peças de 'Defesa Potente' aumenta o Reflexo, garantindo que mesmo ataques rápidos sejam neutralizados.
- **Atributos Principais (Slots II, IV, VI):**
  - **Slot II:** Percepção
  - **Slot IV:** Empenho
  - **Slot VI:** Recepção %
