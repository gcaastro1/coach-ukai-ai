## 🏆 Guia e Dicas

### 🎮 Como Jogar
Como um personagem da posição Li, MICHINARI AKAGI deve focar em cumprir o seu papel base na rotação da equipe. Personagens de raridade menor geralmente são usados no início do jogo ou para fechar sinergias específicas (Vínculos) no banco de reservas.

### ⚙️ Potenciais Recomendados (Builds)
**Opção 1: Build Genérica Recomendada para a Posição**
- **Conjunto:** 4x Recepção Suprema + 2x Recepção Auxiliada
- **Lógica:** Foco total em não deixar a bola cair. Aumenta massivamente os atributos defensivos de fundo de quadra.
- **Atributos Principais (Slots II, IV, VI):**
  - **Slot II:** Passe %
  - **Slot IV:** Reflexo %
  - **Slot VI:** Recepção %
