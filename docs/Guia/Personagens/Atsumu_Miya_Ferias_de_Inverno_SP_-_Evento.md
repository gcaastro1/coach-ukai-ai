## 🏆 Guia e Dicas

### 🎮 Como Jogar
ATSUMU MIYA (Férias de Inverno) é um personagem incrivelmente versátil que pode atuar como Pinch Server agressivo ou como Setter principal. O segredo da sua mecânica é a 3ª habilidade: ao entrar em quadra, os jogadores perdem 50% de vigor, mas recebem um aumento permanente em seus atributos básicos. Se Atsumu permanecer em quadra, ele regenera 15 de vigor por rodada durante 4 rodadas, compensando o custo inicial.

Se você não tiver a Ressonância de Habilidade 2 (SR2), ele consumirá muita energia ao usar a sua Ultimate. Nesses casos, prefira uma formação com dois levantadores e substitua-o pelo Líbero na 4ª rotação para evitar o esgotamento do vigor. Com SR2, a recuperação passiva de vigor permite que ele permaneça em quadra durante toda a partida, funcionando como um suporte de buffs constante e playmaker de elite.

### ⚙️ Potenciais Recomendados (Builds)
**Opção 1: Equilíbrio de Maestro (Recomendada)**
- **Conjunto:** 4x Saque Preciso + 2x Levantamento Preciso
- **Lógica:** O set de 4 peças 'Saque Preciso' garante que o saque nunca falhe (ativando a passiva 'Unconventional Play' constantemente), enquanto o set de 2 peças de levantamento mantém os passes precisos e buffados. Esta build foca em estatísticas de Passe nos slots de main stat para máxima eficiência do time.
- **Atributos Principais (Slots II, IV, VI):**
  - **Slot II:** Passe
  - **Slot IV:** Recepção %
  - **Slot VI:** Passe %

**Opção 2: Pinch Server Agressivo**
- **Conjunto:** 4x Saque Preciso + 2x Levantamento Preciso
- **Lógica:** Foca no poder bruto de saque (Saque Preciso) para maximizar as chances de 'Aces' e pressão constante sobre a recepção adversária. Os main stats priorizam o Saque.
- **Atributos Principais (Slots II, IV, VI):**
  - **Slot II:** Saque
  - **Slot IV:** Recepção %
  - **Slot VI:** Saque %

**Opção 3: Suporte de Elite (Foco em Buffs)**
- **Conjunto:** 4x Levantamento Preciso + 2x Saque Preciso
- **Lógica:** Foca inteiramente no atributo de Passe (Set) para extrair o máximo das habilidades 'Careful Toss' e 'Sincere and Dedicated Toss', aumentando a Técnica de Ataque dos atacantes aliados.
- **Atributos Principais (Slots II, IV, VI):**
  - **Slot II:** Passe
  - **Slot IV:** Bloqueio %
  - **Slot VI:** Passe %
