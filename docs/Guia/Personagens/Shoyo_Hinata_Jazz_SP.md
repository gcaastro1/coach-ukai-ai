## 🏆 Guia e Dicas

### 🎮 Como Jogar
SHOYO HINATA (Jazz) é o Middle Blocker que dita o tom da partida.

## Mecânica Principal
* **Support Stacks:** Cada ação perfeita gera stacks de Suporte. No final do rali, esses stacks são consumidos para buffar a Força e o Empenho de todos os aliados no rali seguinte. O objetivo é manter o rali fluido para acumular o máximo de buffs.
* **Correção Automática:** Ele possui uma mecânica passiva onde, uma vez por rali, se uma recepção resultar em 'bad', ele converte o resultado automaticamente para 'perfect'. Isso é essencial para não quebrar o seu combo de ataques rápidos.
* **Sinergia:** Ele combina perfeitamente com atacantes rápidos que se beneficiam de stats de Força e Empenho aumentados. Mantenha-o em quadra sempre que precisar de estabilidade defensiva e consistência ofensiva.

### ⚙️ Potenciais Recomendados (Builds)
**Opção 1: Maestro da Sincronia (Suporte e Bloqueio)**
- **Conjunto:** 4x Bloqueio Preciso + 2x Movimento de Bloqueio
- **Lógica:** O set 'Bloqueio Preciso' de 4 peças potencializa o seu papel de bloqueador central. O set 'Movimento de Bloqueio' de 2 peças é essencial para manter o atributo base de bloqueio no topo, garantindo que o seu *Support Effect* (Sinergia) seja ativado com sucesso.
- **Atributos Principais (Slots II, IV, VI):**
  - **Slot II:** Força
  - **Slot IV:** Bloqueio %
  - **Slot VI:** Bloqueio %
